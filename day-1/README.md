## 🧠 Key Learnings

* Objects store related data using **key-value pairs**.
* Dot notation is used for fixed property names.
* Bracket notation is used when the property name is stored in a variable.
* `for...in` loops iterate through object keys.
* Objects can be updated, extended, and modified dynamically.
* Meaningful variable names make code easier to read and maintain.
